# TX Criminal Courts — Exec Summary (structure / access inventory)

Paste-ready bullets. Research date: **2026-09-17** (America/Chicago). Full study: [`docs/feasibility/TX-criminal-courts.md`](TX-criminal-courts.md).  
Scope: court **layouts** + how courts **serve** data. No product / Bronze framing. ADR deferred — inventory only.

- **Criminal path:** Trial (municipal/JP → county-level → district) → **1st–14th Courts of Appeals** → **Court of Criminal Appeals**. Death sentences appeal **directly** to the CCA. **Supreme Court of Texas** = civil/juvenile last resort — **not** the criminal high court. **15th Court of Appeals** = statewide civil/business intermediate — **not** the ordinary criminal path. (OCA Sept 2026 chart; Const. art. V; CCP ch. 4.)
- **Official counts (OCA Sept 2026):** District **517** (13 designated criminal district courts; 419 one-county / 98 multi-county); constitutional county **254** (1/county); statutory county **262** (92 counties + 2 multi-county covering 6); JP **798** courts / **799** judges; municipal **954** courts / **1,241** judges (**224** courts of record); Courts of Appeals 1st–14th **14**/80 justices; CCA **1**/9; SCOTX **1**/9; 15th COA **1**/3.
- **254-county map:** Every county has a constitutional county court + JP precincts + connection to ≥1 district court. Statutory county / county criminal courts exist only where created (metro-heavy). Municipal courts only in cities. Specialty drug/veterans/etc. programs sit **inside** existing district/county dockets — no separate statewide portal.
- **Custodian split (typical):** District clerk = felonies / criminal district; county clerk = Class A/B misdemeanors (constitutional or statutory county courts); JP = precinct Class C; municipal clerk = city Class C/ordinance. Appeals from non-record JP/most municipal courts are often **trial de novo**.
- **re:SearchTX (statewide portal):** Interactive search + paid docs across 254 counties — but official FAQ: **all case types except criminal**; **JP also excluded**. No public criminal bulk/API. OCA notes criminal CASE NOTICES only after CMS integration — not the same as public criminal search today.
- **OCA CARD / data.texas.gov:** Statewide **aggregate** criminal caseload statistics only — no party/disposition dockets.
- **TAMES (`search.txcourts.gov`):** Interactive appellate search (CCA + courts of appeals criminal track included). Site states it does **not** maintain trial-court records.
- **eFile Texas:** Statewide **filing** channel; not a public criminal records warehouse. Public research points to re:SearchTX/local clerks (criminal still excluded from re:SearchTX search).
- **Trial serving methods (reality):** Mostly county interactive web + clerk counter/paper; some **paid subscriber** portals (e.g. Tarrant Web Based Access); **published bulk datasets rare** (clearest example: Harris District Clerk Public Datasets). No documented statewide criminal trial REST/bulk feed.
- **Metro snapshot (serving only):** Harris = interactive eDocs + official criminal bulk datasets; Dallas = PublicAccess interactive + counter (felony docs post-2009 online stated); Tarrant = paid subscriber interactive; Bexar = Odyssey Justice Information Portal interactive; Travis = Odyssey portal interactive (criminal ~2008+) + docket search — bulk licensing unclear without clerk confirmation.
- **Inventory gaps still open:** (1) county-by-county which clerks publish bulk vs interactive-only; (2) whether/when re:SearchTX will expose **public** criminal search (vs clerk notice integration only); (3) CATX public/commercial access terms if any; (4) complete JP/municipal electronic coverage map; (5) statutory county-court criminal-jurisdiction variance by creating statute.
